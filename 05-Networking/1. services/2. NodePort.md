## Definition

**NodePort** exposes the application on a fixed port of every Kubernetes worker node. The application becomes accessible using the **Node IP + NodePort**.
### Features

- Accessible from outside the cluster.
- Opens the same port on every worker node.
- Automatically creates a ClusterIP Service.
- Default NodePort range:  
    **30000–32767**
### Use Cases

- Testing applications
- Development environment
- Labs and learning
- Small production environments
## Architecture

```bash
Internet
     |
Node IP:30080
     |
 NodePort Service
     |
    Pods
```
### Create a NodePort Service using kubectl
```bash
kubectl expose deployment nodeport-svc \
--type=NodePort \
--port=80 \
--target-port=80
```
### YAML
```bash
apiVersion: v1
kind: Service
metadata:
  name: nodeport-svc
spec:
  type: NodePort
  selector:
    app: nginx
  ports:
  - port: 80
    targetPort: 80
    nodePort: 30080
```

Verify:
```bash
# Apply the yaml
kubectl apply -f clusterip.yaml

# Verify
kubectl get svc

# Get the services yaml
kubectl get svc nodeport-svc -o yaml
```
Access:
```bash
http://<Node-IP>:30080
```
