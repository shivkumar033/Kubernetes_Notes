## Definition

**ExternalName** maps a Kubernetes Service to an **external DNS name**. It does not create a proxy or load balance traffic; instead, Kubernetes returns a DNS CNAME record pointing to the external host.
### Features

- No selector required.
- No Pods required.
- No Cluster IP assigned.
- Used to access external services by a Kubernetes Service name.
### Use Cases

- External databases
- Third-party APIs
- Legacy applications
- External web services
## Architecture

```bash
Application
      |
ExternalName Service
      |
database.example.com
```

YAML:
```bash
apiVersion: v1
kind: Service
metadata:
  name: external-db
spec:
  type: ExternalName
  externalName: database.example.com
```

Apply:
```bash
kubectl apply -f externalname-service.yaml
```
