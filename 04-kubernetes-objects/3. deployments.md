A **Deployment** is a Kubernetes object that:

- Manages **ReplicaSets**
- Controls **Pods**
- Handles **updates, rollbacks, and scaling**

In production, you almost always use **Deployment instead of ReplicaSet directly**

# Core Idea

Deployment = **Declarative App Manager**

You define:
```php
replicas: 3
image: nginx:1.25
```

Kubernetes ensures:
- 3 Pods running
- Correct version
- Smooth updates

## Architecture (Very Important)
```php
Deployment
   ↓
ReplicaSet
   ↓
Pods
```
- Deployment never directly manages Pods  
- It manages ReplicaSets, which manage Pods

# Key Features of Deployment

### 1. Rolling Updates (Zero Downtime)

When you update the image:
```php
kubectl set image deployment/nginx nginx=nginx:1.26
```

Kubernetes:
- Creates new ReplicaSet
- Gradually replaces old Pods
- Keeps app running
### 2.  Rollback
```php
kubectl rollout undo deployment/nginx
```
Instantly revert to previous version

### 3. Scaling
```php
kubectl scale deployment nginx-deployment --replicas=5
```

### 4. Self-Healing
- If Pod crashes → recreated automatically
- Handled via ReplicaSet

## Example: Deployment YAML
```php
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx-deployment
  labels:
    type: prod-test
spec:
  replicas: 3
  selector:
    matchLabels:
      app: nginx
  template:
    metadata:
      labels:
        app: nginx
    spec:
      containers:
      - name: nginx
        image: nginx:latest
        ports:
        - containerPort: 80
```

#### Create a deployment YAML file using command
```bash
kubectl create deploy deploy/nginx-new \
  --image=nginx:latest \
  --dry-run=client \
  -o yaml > deployment.yaml
```

## How Rolling Update Works (Step-by-Step)

### Initial State:
- ReplicaSet v1 → 3 Pods (nginx:1.25)

### After Update:
- ReplicaSet v2 created (nginx:1.26)

Process:
1. Create 1 new Pod
2. Delete 1 old Pod
3. Repeat

No downtime

### How to check the Rollout history
```bash
kubectl rollout history deploy/ngnix-deployment
```

### How to get rollback for previous version
```bash
kubectl rollout undo deploy/ngnix-deployment
```
