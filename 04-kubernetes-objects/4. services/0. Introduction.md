## What is a Service?

A **Service** is an abstraction that provides a **stable network endpoint** to access a group of Pods.

### Why do we need a Service?

- Pods are **ephemeral** (they can be created and deleted anytime).
- Pod IP addresses change whenever Pods are recreated.
- A Service provides:
    - Stable IP address
    - Stable DNS name
    - Load balancing across Pods
### How Service Works
```bash
              Client
                 |
                 |
          Kubernetes Service
          (Stable IP/DNS)
                 |
      -----------------------
      |          |          |
    Pod 1      Pod 2      Pod 3
```

The Service forwards traffic to all matching Pods using **labels**.

### Components of a Service
### Selector
Identifies which Pods belong to the Service.

Example:
```bash
selector:
  app: nginx
```
Pods with label: 
```bash
labels:
  app: nginx
```
will receive traffic.
### Port

- `port` → Port exposed by the Service
- `targetPort` → Port inside the container

Example:
```bash
ports:
- port: 80
  targetPort: 8080
```

Traffic flow:
```bash
Client ---> Service:80 ---> Container:8080
```
