## Definition

**ClusterIP** is the default Kubernetes Service type. It exposes an application **only inside the Kubernetes cluster**. It cannot be accessed from outside the cluster.
### Features

- Default Service type.
- Internal communication only.
- Provides a stable IP and DNS name.
- Load balances traffic among Pods.
- Used for communication between microservices.
### Use Cases

- Backend APIs
- Databases (MySQL, PostgreSQL)
- Internal applications
- Microservices

## Architecture

```bash
Pod A
   |
ClusterIP Service
   |
Pod B
```

### YAML
```bash
# ClusterIP (Default)
apiVersion: v1
kind: Service
metadata:
  name: nginx-service
spec:
  type: ClusterIP
  selector:
    app: nginx
  ports:
  - port: 80
    targetPort: 80
```

Command:
```bash
# Apply
kubectl apply -f clusterip.yaml

# Verify
kubectl get svc

kubectl describe svc nginx-service
```

Access the Pod In Browser:
```bash
# Use `kubectl port-forward`
kubectl port-forward svc/my-app 8080:80

# Now open your browser: http://localhost:8080
----------------------------------------------------
# If you're using Minikube
# Run
minikube service my-app
minikube service my-app --url
----------------------------------------------------
# If you're using Kind
kubectl port-forward svc/my-app 8080:80
```
