A **DaemonSet** ensures that **one Pod runs on every eligible Node** in a Kubernetes cluster.
#### Example:
```bash
Cluster
├── Node 1 → nginx Pod
├── Node 2 → nginx Pod
└── Node 3 → nginx Pod
```

When a new Node is added:
```bash
Node 4 → nginx Pod automatically
```
### Why use DaemonSet?

Common use cases:
- 📋 **Log collection** — Fluent Bit/Fluentd on every node
- 📊 **Monitoring** — Node monitoring agents
- 🔒 **Security** — Security agents on every node
- 🌐 **Networking** — Network-related agents
- 💾 **Storage** — Node-level storage agents

**Example: DaemonSet YAML**
```php
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: fluentd-daemon
spec:
  selector:
    matchLabels:
      app: fluentd
  template:
    metadata:
      labels:
        app: fluentd
    spec:
      containers:
      - name: fluentd
        image: fluentd:latest
```

Command:
```bash
# Apply it
kubectl apply -f daemonset.yaml

# Check DaemonSet
kubectl get daemonset

# Check Pods
kubectl get pods -o wide

# Details Information
kubectl describe daemonset nginx-daemonset

# Delete DaemonSet
kubectl delete daemonset nginx-daemonset

# Edit DaemonSet
kubectl edit daemonset nginx-daemonset

# See DaemonSets in all namespaces
kubectl get daemonset -A
```
